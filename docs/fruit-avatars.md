# Fruit avatars

Each fruit owns its colours and vector paths. Users select a fruit in the character picker.

Coconut stores explicit choices in the existing avatar field as `fruit.<id>`. The app maps old avatar values through a fixed list. Adding fruits must not change that list or move existing identities.

Before accepting new artwork, inspect every fruit in the native app at 18, 24, 40, 56, and 96 points. Check both eyes and the mouth through a full animation cycle. A large preview does not prove readability.

The native character test checks selection and persistence. Visual checks cover face placement and motion.

Bot names remain visible. Bots maintain their routing descriptions in native Hermes profile metadata. Coconut shares those short descriptions with other bots. It does not share private instructions or memory.
