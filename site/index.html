How it works

Your Mac runs Hermes and Coconut and stores the work. Your iPhone reaches the Mac through a shared Cloudflare relay, end to end encrypted.

iPhoneNative SwiftUI app
RelayForwards ciphertext only
Your MacHermes + Coconut, loopback only
  • Coconut listens only on 127.0.0.1. The Mac opens no port.
  • A sidecar keeps an outgoing connection to the relay. No VPN.
  • The relay sees route IDs, timing, and sizes. Never content.
  • Notifications ride the same relay, so you need no Apple push keys.

Setup is one message.

If you already use Hermes, onboarding is one screen on the iPhone. It shows a single command to send to your Hermes agent, for example in Telegram.

Install the iPhone app

Coconut ships through TestFlight. The app opens onboarding on first launch.

Send one message to Hermes

Paste the command from the onboarding screen into any chat with your Hermes agent. It installs Coconut.app on the Mac.

Pair

The Mac seals a setup for your iPhone with a one-time code. The phone opens it and pairs by itself.

# The message the iPhone shows. Hermes runs it on the Mac.
curl -fsSL https://coconut-updates.gumroad.workers.dev/install | bash -s <code>

Your Mac keeps the work.

Coconut runs on the Hermes you already use. It does not install its own copy. Bots are Hermes profiles, so a bot in Coconut and hermes -p name in Terminal are the same agent.

  • Pairing uses Noise IKpsk2 with a one-time secret. Sessions use Noise IK.
  • Only the paired Mac can finish a handshake. Only paired iPhones are answered.
  • Model keys stay in Hermes. Coconut never prints a key.
  • Uninstall removes Coconut's data. Your Hermes, profiles, and memories stay.
Coconut is a thin client over Hermes. Not affiliated with Nous Research.
